สถานะในผลลัพธ์ (เรียงตามความสำคัญ)

      
คอลัมน์ category บอกว่าแถวนี้มาจากส่วนไหน: ยาฉีด/สารน้ำ และ/หรือ กลุ่มกฎส่วนที่ 2 (เฝือก, ตรวจภายใน, พ่นยา ฯลฯ) · ถ้าผิดกฎส่วนที่ 2 จะนับเป็น คีย์ไม่ครบ

      

        
statusความหมาย / สิ่งที่ต้องทำ

        
ไม่ครบ+เกินบางกลุ่มขาด บางกลุ่มเกิน ดูคอลัมน์ need_add และ need_check_remove

        
คีย์ไม่ครบมียาฉีด/สารน้ำ แต่ไม่มีค่าฉีดหรือค่าให้สารน้ำ (หรือไม่มีค่าเข้าข้อ/IL) → เพิ่มตาม need_add

        
คีย์เกินค่าฉีด/สารน้ำมากกว่าจำนวนยา → ตรวจและตัดตาม need_check_remove

        
ตรวจจำนวนค่าฉีดน้อยกว่าจำนวนยา (ขึ้นเฉพาะเมื่อเปิด check_qty) ถ้าไม่ได้ผสม drip อาจขาด

        
ตรวจวิธีใช้จำนวนรวมครบ แต่กลุ่มไม่ตรง เช่น วิธีใช้ IM แต่คีย์ 71820 → แก้วิธีใช้ในใบสั่งยาให้ตรงที่ให้จริง

        
นำยามาเอง?มีค่าฉีดแต่ไม่มียาใน visit และมีหลักฐาน (CC หรือเคยจ่ายยาฉีด ≥2 หน่วยใน N วันก่อน) → ตรวจก่อนตัด

ส่วนที่ 1: หลักการเทียบยาฉีด/สารน้ำ

      
    
        
  • เทียบแบบรวม: ยาฉีด IV/IM/SC + สารน้ำ เทียบกับค่าฉีด 55822/55823/55824 + ค่าให้สารน้ำ 55820 (ไม่สน route ที่คีย์ กันกรณี tramadol สั่ง IV แต่วิธีใช้ default IM)
    • 
        
  • ฉีดเข้าข้อ 71711 + intralesion 71820 เทียบรวมเป็นกลุ่มหัตถการ · RIG ฉีดรอบแผลนับเป็น intralesion
    • 
        
  • ยาฉีดจ่ายล่วงหน้ารายเดือน (qty > 1, q 1 mo / ทุกเดือน) ไม่บังคับมีค่าฉีด แต่มีก็ไม่นับเกิน
    • 
        
  • วัคซีนพิษสุนัขบ้า/ยา ID: ยอมรับค่าฉีดกลุ่มใดก็ได้ สูงสุด 2 รายการต่อยา
    • 
        
  • NSS/D5/SWI ขนาดเล็ก (≤100 ml, amp/vial) หรือวิธีใช้ผสม/ละลายยา = ตัวทำละลาย ไม่ต้องมีค่าฉีด
    • 
        
  • ยาชา (lidocaine, bupivacaine ฯลฯ) = ยาประกอบหัตถการ ไม่ต้องมีค่าฉีดของตัวเอง
    • 
        
  • NSS/SWI ใน visit ที่มีพ่นยา/ทำแผล หรือวิธีใช้ ≤20 ml = ไม่ใช่สารน้ำ
    • 
        
  • มี ICD10 Z51.8/Z51.9 ไม่ตรวจกรณีค่าฉีดมากกว่ายา แต่ยังตรวจกรณีขาด
    • 
        
  • ตัดออก: ยาใช้ภายนอก, glucose กินทดสอบในฝากครรภ์, ยาฉีดกลับบ้าน (insulin pen, วิธีใช้ก่อนอาหาร/ฉีดเอง)
    • 
        
  • เฉพาะ OPD (ไม่มี AN)
