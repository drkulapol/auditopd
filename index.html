ส่วนที่ 1: หลักการเทียบยาฉีด/สารน้ำ

      
    
        
  • เทียบแบบรวม: ยาฉีด IV/IM/SC + สารน้ำ เทียบกับค่าฉีด 55822/55823/55824 (SC/ID) + ค่าให้สารน้ำ 55820 (ไม่สน route ที่คีย์ กันกรณี tramadol สั่ง IV แต่วิธีใช้ default IM)
    • 
        
  • ฉีดเข้าข้อ 71711 + intralesion 71820 เทียบรวมเป็นกลุ่มหัตถการ · RIG ฉีดรอบแผลนับเป็น intralesion
    • 
        
  • ยาฉีดจ่ายล่วงหน้ารายเดือน (qty > 1, q 1 mo / ทุกเดือน) ไม่บังคับมีค่าฉีด แต่มีก็ไม่นับเกิน
    • 
        
  • วัคซีนพิษสุนัขบ้า (PCEC/rabi/verorab/speeda หรือวัคซีนใน visit ที่มี Z24.2/Z20.3) และยา ID: IM 1 จุด (55823) หรือ ID 2 จุด (55824 x2) ยอมรับค่าฉีดกลุ่มใดก็ได้ สูงสุด 2 รายการต่อยา
    • 
        
  • NSS/D5/SWI ขนาดเล็ก (≤100 ml, amp/vial) หรือวิธีใช้ผสม/ละลายยา = ตัวทำละลาย ไม่ต้องมีค่าฉีด
    • 
        
  • ยาชา (lidocaine, bupivacaine ฯลฯ) = ยาประกอบหัตถการ ไม่ต้องมีค่าฉีดของตัวเอง
    • 
        
  • NSS/SWI ใน visit ที่มีพ่นยา 55320, ทำแผล 55810–55812, ล้างตา 55210 หรือวิธีใช้ ≤20 ml = ไม่ใช่สารน้ำ
    • 
        
  • มี ICD10 Z51.8/Z51.9 ไม่ตรวจกรณีค่าฉีดมากกว่ายา แต่ยังตรวจกรณีขาด
    • 
        
  • มีค่าฉีดแต่ไม่มียาฉีดเลย และไม่มี 55020/55021 = มาฉีดยาตามนัด (นำยามาเอง) ไม่แสดงในรายการ
    • 
        
  • ตัดออก: ยาใช้ภายนอก, glucose กินทดสอบในฝากครรภ์, ยาฉีดกลับบ้าน (insulin pen/penfill, insulin 300 IU, วิธีใช้ก่อนอาหาร/ฉีดเอง)
    • 
        
  • เฉพาะ OPD (ไม่มี AN)
